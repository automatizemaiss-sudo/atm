# ATM+

Landing page institucional da ATM+, criada para apresentar soluções de automação e inteligência artificial aplicadas a vendas, atendimento e operação.

## Desenvolvimento local

Requisitos: Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```

## Tecnologias

- Next.js e React
- TypeScript
- Vinext e Vite
- CSS responsivo

## Estrutura principal

- `app/page.tsx`: conteúdo e componentes da landing page
- `app/globals.css`: identidade visual e responsividade
- `public/`: logos e imagens utilizadas no site

Todos os CTAs direcionam para a agenda de reuniões da ATM+.
